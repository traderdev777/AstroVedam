3. Technical Diagnosis & Root Cause Isolation

Rigorous mathematical analysis of src/engines/astrology/ephemeris.js isolated five distinct defects in the legacy Jupiter and Saturn formulations:

Defect 1: Fixed J2000 Equinox Rate vs. Equinox-of-Date Precession Drift (Primary Error)

The legacy code defined mean longitudes $L$ with fixed J2000 linear rates ($3034.905675^circ/ ext{cy}$ for Jupiter; $1222.113794^circ/ ext{cy}$ for Saturn). While mathematically correct in an inertial frame, JPL Horizons (QUANTITIES='31') and AstroVedam's Earth heliocentric vector evaluate coordinates in the equinox of date. Because general precession in longitude advances at $+5028.79''/ ext{cy} approx +1.396886^circ/ ext{cy}$, the legacy formulas fell behind by $1.397^circ$ per century. By 2023, accumulated error reached $Delta L approx 19.7'$, explaining the severe secular negative drift in cases REF-05, REF-06, and REF-07.

Defect 2: Saturn Perturbation Phase Sign Inversion

In ephemeris.js line 257, Saturn's 4th perturbation term was coded as + 0.046 * sin(2*Mj - 6*Ms + 69). Cross-referencing Paul Schlyter Section 10 and Jean Meeus Chapter 31, the true astronomical argument is (2*Mj - 6*Ms - 69). This inverted sign produced a spurious $+2.42'$ offset at J2000, causing baseline failures across REF-01 through REF-04 and REF-09.

Defect 3: Omission of Planetary Light-Time Retardation ($ au = d/c$)

Planetary distance causes finite light travel time $ au = d/c$ (33–51 min for Jupiter; 65–87 min for Saturn). During transit, Earth displaces along its orbit, shifting the geocentric sight-line by $1.5'$ to $3.5'$. Neglecting light travel time systematically degraded apparent planetary coordinates.

Defect 4: Kepler Equation Center Truncation

Equation of center was approximated via a truncated 2-term Taylor series. For Saturn ($e approx 0.0555$), neglecting higher-order terms $O(e^3)$ lost up to $0.4'$ of orbital geometry accuracy.

4. Justified Astronomical Equations (Meeus Table 31.A / Simon et al. 1994)

Coordinates were upgraded to Meeus (1998) Table 31.A equinox-of-date expansions, with Newton-Raphson Kepler solver and light-time iteration:

// 1. Solve Kepler Equation: E - e * sin(E) = M (Bounded 6 Iterations)
function solveKepler(Mrad, e) {
  let E = Mrad + e * Math.sin(Mrad);
  for (let i = 0; i < 6; i++) {
    const dE = (E - e * Math.sin(E) - Mrad) / (1 - e * Math.cos(E));
    E -= dE;
    if (Math.abs(dE) < 1e-12) break;
  }
  return E;
}

// 2. Light-Time Iteration & Retardation (tau = 0.0057755183 * distance)
const d0 = Math.sqrt((pos0.x - earth.x)**2 + (pos0.y - earth.y)**2);
const tau = 0.0057755183 * d0; // days
const posRetarded = getPlanetHelio(julianCenturies(jd - tau));

// 3. True Apparent Equinox Alignment (IAU 1980 Principal Nutation)
const dPsi = (-17.20 * Math.sin(Omega) - 1.32 * Math.sin(2 * L0)) / 3600;
return norm360(Math.atan2(posRetarded.y - earth.y, posRetarded.x - earth.x) * RAD + dPsi);
