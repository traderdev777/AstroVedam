2. Remediated Defects & Technical Solutions

Defect Root Cause Remediation Implemented Status
Fix 1: Sade Sati vs Dhaiya Labels Kantaka (4th) & Ashtama (8th) Shani rendered as Active Sade Sati in reports. Added distinct localized Dhaiya statuses across all 5 languages (e.g. Active Dhaiya (Kantaka / Ashtama Shani) in EN, शनि ढैया सक्रिय (कंटक / अष्टम) in HI). Dhaiya is never labeled as Sade Sati. RESOLVED
Fix 2: Invalid Transit Non-Favorable Contract Invalid dates & missing Moon signs silently defaulted to Clear / Favorable (दोष मुक्त). Implemented strict 3-state contract (valid/affected, valid/unaffected, invalid/unavailable). Renders localized slate-gray (#64748B) unavailable state; never favorable. RESOLVED
Fix 3: Safe getRashi() Normalization getRashi(360.0) returned out-of-bounds sign 13, causing runtime TypeError. Safely normalized modulo 360 to [0, 360) so zsh^\circ, 360^\circ, 720^\circ ightarrow$ sign 1 (Aries). Negative angles normalize correctly (569X30^\circ ightarrow 12$). Non-numbers & NaN return null safely. RESOLVED
Fix 4: Transit Assessment Date Display Reports did not disclose what assessment date was used, causing confusion with birth date. Unified single assessment date flow through ephemeris, doshas, predictions, reports, and AstroGuru. Displayed on Page 3 and seeker strip. Date-only parsed at UTC midday. RESOLVED
